Netflix UI Clone 

A clean, responsive front-end clone of the Netflix landing page built using pure HTML5 and CSS3.

Live Demo:
[View Live Site](https://movie-streaming-ui-ashen.vercel.app/)

 Key Features:
- Responsive Design: Fully optimized for mobile, tablet, and desktop screens.
- Modern Layouts: Built using CSS Flexbox and Grid.
- Clean Structure: Semantic HTML5 for better accessibility and SEO.

 Tech Stack:
- HTML5
- CSS3
- Vercel (Deployment)
